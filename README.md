NEON TIDE is an original open-world crime game set in Solara Bay, a sun-soaked coastal city built from scratch in 2D canvas. Kai, a courier driver with one bad night ahead of him, explores the city on foot and by car, steals cars, outruns the Solara Bay police under a five-star wanted level, shoots it out with a rival crew, and finishes three linked story missions — a pier pickup, a police escape, and a final getaway run to the North Bridge. Traffic and pedestrians fill the streets, the HUD carries a live minimap, mission objectives and a wanted display, and progress saves automatically. All art is drawn in code and all sound is synthesized with WebAudio; the game loads nothing from the network.

## Run it

```sh
node serve.ts
```

Run `node serve.ts` inside the kit directory, then open http://localhost:8080 in a desktop browser. Move with WASD, aim with the mouse, click to shoot, press E to enter or steal a car, Space for the handbrake, P to pause, M to mute.
